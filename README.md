# Telco Customer Churn Analysis

## 📌 Project Overview
Analyzed 7,043 customer records to identify churn drivers and business impact
for a telecom company. Identified a 26% overall churn rate and delivered
actionable recommendations to reduce churn by ~15%.

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy)
- Jupyter Notebook
- Power BI (2-page interactive dashboard)

## 📊 Key Findings
- 26% overall churn rate across 7,043 customers
- Month-to-month contracts = highest risk segment (1,655 cases flagged)
- Churned customers paid ₹74 avg monthly vs ₹61 for retained customers
- Tiered pricing strategy recommended to reduce churn by ~15%

## 📂 Dataset
Uses the [Telco Customer Churn dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) from Kaggle.
- 7,043 customer records · 21 features
- Download CSV and place in project folder as `telco_churn.csv`

## 📷 Dashboard
Power BI -page interactive dashboard included for stakeholder review.

## 🚀 How to Run
1. Download dataset from Kaggle link above
2. Place CSV in same folder as the notebook
3. Open `telco_churn_analysis.ipynb` in Jupyter
4. Run all cells step by step
